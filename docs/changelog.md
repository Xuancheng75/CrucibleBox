# CrucibleBox 更新日志（Tauri 线）

> 覆盖 tauri-v1.9.2（首个 Tauri 正式版）起的用户可感知变更。
> Electron 1.7.x 线已冻结，历史见 `docs/electron-legacy-registry.md`。

## 1.9.24（2026-08）

稳定性封版：

- 修复小窗口模式下侧边栏随主页面滚动的问题；应用根布局固定为窗口高度，仅主内容区滚动。
- 修复打开 Document Engine 时 GPU 探测进程导致的控制台闪窗；宿主与 OCR Worker 均使用隐藏进程并缓存探测结果。
- Document Engine 0.3.0 统一 OCR 任务进度快照，加入递增序号、页码范围、冷/热模型状态和识别阶段，避免 5%/20% 反复跳动。
- PDF OCR 按页传递进度并限制任务快照和结果预览大小，2000 页任务不会把完整结果塞入 RPC 消息。
- UniEnv 0.9.0 增加 Ruby、Zig、Deno、Bun 工具链及 Ruby Web、Zig 原生、现代 TypeScript、多运行时 Web 组合包；新增工具使用官方发布摘要校验。
- 统一应用与插件版本基线，README、架构文档和安全模型更新至 1.9.24。

1.9.24 是 1.9 系列封版版本；后续仅接受安全修复和严重故障热修复，新架构与大型功能转入 2.0。

## 1.9.23（2026-08）

稳定性与导入：

- 源码目录导入会忽略 `node_modules`、`.pnpm`、`.git` 和 `target` 开发目录，保留实际插件载荷的符号链接拒绝策略；Diary 源码目录不再因 pnpm 链接误报。
- 更新下载增加内容解码错误识别、三次退避重试和 `identity` 编码请求，下载中断后自动重新校验签名包。
- 应用图标补齐 16–256 DPI 资源并强制刷新安装器图标缓存，降低更新/首次启动时任务栏模糊问题。

功能拓展：

- Document Engine 0.2.1 的切分页面提供文件夹选择器，任务结果显示可复制的输出路径。
- UniEnv 0.8.0 增加 Rust stable/beta/nightly 通道与 PHP 8.2/8.3/8.4 NTS x64 版本，并保留 SHA-256 固定制品校验。
- 转盘抽奖 0.2.0 增加防连续重复中奖和最近中奖记录；JSON 工具箱 0.2.0 增加点路径 JSONPath 查询；实时汇率 0.2.0 增加备用数据源标识；剪贴板管理器 0.2.0 即时记录主动复制并支持仅置顶筛选。
- GIF 编辑器 0.4.0 支持帧多选批量删除；系统信息面板 0.2.0 增加低频趋势采样；骰子与随机数 0.2.0 支持 `NdM±K` 表达式；主题管理器 0.2.0 增加纸张编辑与终端绿两套结构化主题。

## 1.9.22（2026-08）

修复与稳定性：

- 修复单个插件初始化、可信服务或网络调用超时持有核心数据库锁，导致工作台、插件日志、设置和其他插件一起无法加载的问题；数据库锁改为按需短持有，插件激活按插件单飞。
- 插件请求超时只终止故障插件并保留可重试状态，不再把整个工具箱置于永久 Loading。
- 任务进度统一为单调递增；大型任务结果自动生成受限预览，避免 `PAYLOAD_TOO_COMPLEX` 触发后不断轮询。
- PDFium 任务状态支持进程级复用，PDF 解析页数上限明确为 2000 页，超限任务在开始前给出提示。

Document Engine 0.2.0：

- 新增按页、按章节/标题、按结构、按语义/长度和混合切分选项。
- 切分结果可写入配置的输出目录，并在任务结果中显示输出路径；输出目录暂不可写时保留内存结果并返回可操作的错误说明。
- 概览导入文件继续共享到解析、转换和切分页面；结果列表保留页数、字节数和预览信息。

UniEnv 0.7.0：

- 修复 Rust、PHP 版本下拉目录与宿主不一致导致的空列表。
- 安装完成后可将 UniEnv 轻量 shim 目录加入当前用户 PATH，版本切换无需重复增长 PATH。
- 新增 Rust 开发、PHP Web 和多语言后端组合包。

主题与体验：

- 主题管理器 0.1.14 新增暖阳米白、樱花粉、琥珀秋日、极简黑白、雾霾蓝、薰衣草、墨色东方和极光夜色八套主题。
- 批量插件操作和组拖拽继续保持失败项可重试、排序可回滚。
- 剪贴板管理器改为事件驱动刷新，复制或系统剪贴板变化后立即更新历史，移除高频轮询以降低内存与 IPC 开销。

## 1.9.21（2026-08）

修复：

- 插件多次中断升级后恢复器不再因旧 stage/backup journal 叠加而永久阻断；当 target、数据库和
  最新升级 journal 一致时自动清理更早的残留事务，顺序或元数据不确定时继续保持安全阻断。
- 插件排序请求增加单飞保护，生命周期操作、安装队列和刷新期间不会覆盖正在提交的顺序。
- 应用更新检查增加 12 秒请求超时、一次网络抖动重试和并发检查锁；GitHub 暂时不可达时会
  自动结束检查并显示可操作的错误提示，不再永久停留在“正在检查更新”。

新增与优化：

- 主页批量管理支持手机式多选组拖拽：先选择多个插件，长按任一已选卡片拖动整组，保持组内
  相对顺序，并在失败时自动回滚。
- 内部插件排序拖拽与全局文件/ZIP 拖入建立来源隔离；Document Engine 文件导入和工具箱插件
  包导入继续支持混合拖放，不会被卡片排序手势误触发。
- 补充 Tauri 前端排序与拖放回归测试、无障碍选中状态和 1.9.21 版本基线说明；Electron 冻结线
  不变。

## 1.9.20（2026-08）

稳定性收尾版：

- 固化插件导入、升级、启停、卸载和崩溃恢复的单飞与可恢复事务，清理中断升级残留，避免卸载后重复出现旧版本升级提示。
- Document Engine 0.1.2 完成发布验收：内置 CPU OCR 默认模型、镜像回退、PDFium 单例绑定、概览导入文件共享，以及 PDF 解析/转换/切分请求的参数校验。
- 批量插件操作保留部分失败项供重试；插件页面和宿主列表错误保留可读原因，便于恢复和诊断。
- 统一 Tauri 版本校验与 README/发布文档基线；根目录 Electron 1.7.3 继续保持冻结。

## 1.9.19（2026-08）

新增与修复：

- 主页批量管理支持批量启用、批量禁用和批量删除，按插件串行执行并保留失败项供重试。
- 导入、升级、启用、禁用、卸载和崩溃恢复增加插件级生命周期单飞与维护窗口，降低频繁操作引起的进程、会话和临时目录残留。
- 修复已启用插件升级时维护窗口阻止自身重新激活的问题；激活失败会立即回滚，重新导入或卸载可自动恢复残留事务，不再永久显示 `plugin is blocked after an interrupted transaction`。
- Document Engine 修复可选参数序列化，避免 `undefined` 出现在切分与 Markdown 转换请求中；增强 PDF 解析失败提示与回归测试。
- Document Engine 0.1.2 随插件内置 CPU PP-OCRv4 默认模型，新增 jsDelivr/GitHub Release/上游源顺序回退；PDFium 改为进程级单例绑定；概览导入的单个 PDF 可直接用于解析、转换和切分。
- Tauri 发布脚本统一从 `src-tauri/tauri.conf.json` 读取版本，新增版本一致性 CI 门禁；根目录 Electron 1.7.3 保持冻结。
- README 与发布文档同步当前 11 个正式插件和 v1.9.19 验证基线。

## 1.9.18（2026-08）

修复：

- 插件卸载改为可恢复的 journal/quarantine 事务，释放 renderer 会话并阻止维护期间的重复激活/崩溃重启。
- Document Engine 诊断、任务/模型读取链路补齐，支持从工具箱选择文件、多个文件或文件夹导入（文件夹递归枚举最多 1000 个文档）。
- 修复转盘 sidecar `crypto.getRandomValues` 只生成低字节导致几乎永远命中首项的问题，改用 Windows BCrypt 系统随机源。
- 剪贴板管理器启动时自动启用宿主监控，事件投递增加重试，历史写入串行化，复制文本可稳定进入列表。

## 1.9.17（2026-08）

修复：

- **剪贴板管理器无法工作**：sidecar quickjs-ng 无 `setInterval`，插件激活失败。改为宿主侧 Rust 线程轮询剪贴板，经 Tauri 事件转发至插件。
- **实时汇率 "not a function"**：`api.fetch()` 返回纯 JSON 对象而非浏览器 Response，`resp.text()` 报错。改用 `resp.body`。

## 1.9.16（2026-08）

新增四个插件（插件总数 6 → 10）：

- **JSON/文本工具箱**（`json-toolkit`）：JSON 格式化/压缩/校验、Base64 编解码、URL 编解码、时间戳转换、UUID 生成、正则测试、文本哈希（SHA-1/256/384/512）
- **剪贴板管理器**（`clipboard-manager`）：1s 轮询剪贴板变化、持久化历史、搜索/置顶/回填/删除
- **系统信息面板**（`system-info`）：CPU/内存/磁盘/OS/网络信息仪表盘，3s 自动刷新
- **实时汇率**（`exchange-rates`）：调用 open.er-api.com 获取汇率，30 分钟缓存，多币种转换

## 1.9.15（2026-08）

宿主能力扩展（插件 SDK v2 契约不变，仅扩展实现面）：

- **`network.fetch`**：插件 backend 可发起 HTTP 请求（ureq，30s 超时，响应 ≤50MB）
- **`clipboard.read/write`**：插件 backend 可读写系统剪贴板文本（arboard）
- **`file.read/write`**：插件 backend 可读写文件系统
- **`notification.show`**：插件 backend 可发送系统通知（经宿主事件总线转发）
- **`system.info`**：插件 backend 可获取系统信息（CPU/内存/磁盘/OS/网络，无需权限）
- 新增四个插件：JSON/文本工具箱、剪贴板管理器、系统信息面板、实时汇率
- 插件总数从 6 个扩展到 10 个

## 1.9.13（2026-08）

修复版本：

- **导入确认报错**：`plugin_install_commit/discard` 参数键名不匹配（Rust 形参
  `token` vs 前端误传 `installToken`），自 1.9.3 起「确认安装」必失败。现已在
  Tauri 线完整走通 导入→预览→确认 安装链。

  慢网/断网时秒回内置目录。
- **日记返回按钮不居中**：`.nav-btn` 改 flex 居中、`.back-btn` 恢复对称内边距。
- **默认主题顶栏重叠**：Header 由 transparent 改为不透明背景 + 分隔线
  （cyber/neon 主题外观不受影响）。

发布资产新增官方插件包 `unienv-0.6.0.zip` / `diary-0.4.13.zip`：
**从 1.9.12 及更早升级的用户请导入这两个包**以启用 UniEnv 在线新版本与日记
周切换等新功能（NSIS 安装器不会更新 %APPDATA% 内的已装插件）。
