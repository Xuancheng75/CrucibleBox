# 2.1.1 通用导航键盘补修

日期：2026-11-02。P5 复核发现的 P2 平台缺口；P5 当前未完成。

计划要求包含方向键、Enter、Esc、Tab 与可见焦点。原主导航按钮支持原生激活与 Tab，但没有方向键焦点移动；此前仅凭样式和组件证据将 P4 适配源码概括为全面完成，表述过满。本记录修正该范围，不将“已构造主题声明”视为所有交互已实现和验收。

补修位于通用 `IconRail`，不按主题或插件名称分支。侧栏和菜单布局用上下方向键，顶部布局用左右方向键；焦点可循环，Home/End 定位首尾。焦点移动不立即换页；Enter/空格沿用按钮行为，Tab/Esc、修饰键组合和输入法组合输入不被拦截。沿用既有可见焦点样式。

真实组件事件处理回归 4 项通过，覆盖三种布局及键盘保留行为；这不是真实窗口键盘体验验收。完整 `npm run check` 与前端构建通过：宿主前端 124 项、SDK 44 项及供应链既有检查通过；普通权限下的供应链进程查询曾失败，正常权限复验通过。证据在 `.workbench/p5-navigation-*-permitted.log`，原失败日志保留。

导航补修已保存于 `eb8eedc`，后续任务结果恢复和暂停/提交顺序补修后，当前候选固定为 `376eaf7`，八插件生命周期及受影响实际任务自动复验通过；详见 [任务恢复补修](2.1.1-task-result-fix.md)。旧固定点结果单独归档；新候选不自动继承旧产物的完整验收结论。P5 业务记录归独立插件仓库，原生视觉、缩放、输入法和交互体验仍统一留至 P7。正式 Portable 未更新。
