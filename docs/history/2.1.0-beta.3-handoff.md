## 3. OCR 与数学公式：标准档验收及深度档延期

人工校验样本和评分脚本位于忽略目录 `.beta3-tools/math-benchmark/`、`.beta3-tools/ocr-benchmark/`；可重跑 `python scripts/score-math-acceptance.py .beta3-tools/math-benchmark sample-1 sample-2`。两份 OHR-Bench 扫描 PDF 配对人工校验 JSON，共 **9 条**展示公式。严格 LaTeX 匹配只是可重复的指标；`array`/`aligned` 等等价写法与符号错误须分开核查，但**诊断性相似度不能充作通过率**。
