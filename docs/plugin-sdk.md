# 插件能力与开发边界

仅支持 Manifest/API 6、wire 4。公共 JS API/UI 版本为 6.0.0-alpha.2，CLI 为 2.0.0-alpha.2，Rust SDK 为 0.1.0-alpha.1。契约来源是 contracts/next2/contract.json，公共包位于 packages/cruciblebox-next2-*。

| 插件形态 | 执行环境                     | 适用范围                                                       |
| -------- | ---------------------------- | -------------------------------------------------------------- |
| 纯前端   | sandbox iframe、浏览器 JS    | 表单、计算、可视化与本地界面工具                               |
| JS 后端  | 独立 QuickJS runner          | 通过 SDK 使用存储、配置及已声明的平台/服务能力；不提供 Node.js |
| 原生后端 | Windows x64 独立 EXE、wire 4 | 文件处理、外部工具、原生库与长任务；属于可信本地代码           |

平台提供：插件配置与私有 KV（含有界分块/事务）、后台任务及进度/暂停/取消、文件选择和 owner 绑定引用、结果发布、代理路由与 HTTPS 请求、剪贴板、宿主主题预览/提交/回滚、对话框和通知、独立资源包安装/下载/校验/挂载、声明式服务依赖及版本检查。

插件可声明导航、命令和文件处理扩展名；命令面板执行 manifest 映射的后端方法。安装、升级、停用、卸载及退出均经通用生命周期；代码与资源版本化，用户数据位置稳定。签名/发布者、原生代码和权限扩张在安装阶段确认。

新插件只开发、构建与分发自己的代码和资源包，无需修改或重新编译宿主。只有新增当前契约没有的平台能力，才需要独立提出宿主变更。插件名称、业务方法和算法不得写入宿主分支或白名单。

不承诺：旧 API 执行兼容、Node.js 运行时、跨平台原生 ABI 或 OS 安全沙箱。插件业务是否正确需单独验收，底座测试通过不能替代业务验收。
