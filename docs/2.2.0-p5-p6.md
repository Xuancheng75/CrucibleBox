# Next 3.0 P5/P6 固定宿主验收

2026-11-07。P5 复用已交付的界面贡献、公开 API/UI SDK、Provider SDK、构建检查与四类模板；P6 对照任务书 Phase 6 验证纯前端、CLI、后台服务、Capability Provider、Python Runtime 和两个真实业务插件。业务源码、插件身份及逐项业务结果保留在独立插件仓库，宿主只记录通用平台行为。

## 候选与边界

本轮最终开发候选为 2.2.0-beta.3，Manifest 7、API 7、wire 5、data schema 1。公开 API/UI 继续为 7.0.0-beta.2、CLI 3.0.0-beta.2、Rust SDK 0.2.0-beta.2。插件声明的最低宿主仍按所用能力管理；本轮完整验收的固定宿主为 beta.3。

宿主使用工作区内独立目录 .workbench/2.2.0-p6-beta3/fixed-host；安装、数据库、WebView 与测试文件全部隔离。没有注册系统安装、操作正式 Portable 或读取生产插件数据。初始 beta.2 的通用诊断和业务执行通过，但完成时间精确对照失败，不能视为本轮最终固定宿主通过。

## P6 发现与修正

同一成功任务在当前进程显示任务视图的收尾时间，重启后使用已保存执行结果的时间；两者来自不同的时刻，实测相差 3 ms。修复位于 next2_host.rs：终态查询统一使用持久化执行结果的 completedAt；输出已经提交、完整结果尚未保存的窗口继续使用 completedAt=0 表示收尾进行中。失败诊断、核心状态与 owner 裁决保持原有职责。

新增回归使用真实持久任务库与受控提交窗口，核对结果尚未保存时的标记、执行收尾后的查询、关闭并重开任务库后的时间和结果。修复后生成 beta.3，使用全新隔离数据重做诊断、两个业务插件、升级/卸载重装及实际宿主重启，没有把更换宿主混入原候选的通过记录。

## 验证结果

| 范围 | 实测 |
| --- | --- |
| P5 独立工具链 | 从公开 SDK 的 npm 打包形态初始化、构建、check 与 pack，生成纯前端、原生 CLI、后台 Provider、JS/Python 四类包。各插件项目的 Cargo 目标目录与依赖均留在自己的目录中。 |
| 页面与 UI API | 实际 WebView 的 opaque iframe 使用一次性握手和 MessagePort 挂载。公开 UI SDK 跨进程调用 Provider，结果经私有存储返回 26；主题变化触发插件回调并保存新外观。命令清单的工具栏和菜单位置及实际 native 命令调用通过。 |
| 后台与服务 | 无 renderer 的服务实际定时写入自己的 KV；消费者通过声明的能力及 Schema 调用。非法参数拒绝，被启用消费者依赖的服务拒绝停用。重启后，在任何插件调用之前，以只读数据库观测确认后台计数继续增长。 |
| CLI 与 Python | 原生 CLI 执行普通调用、声明命令与宿主任务。Python 资源先报告缺失，经资源导入批准后显示 ready，真实 CPython 接收中文 stdin 并返回输出；运行中任务取消进入已确认终态。运行时夹具来自本机隔离资源，不代表在线运行时分发完成。 |
| 两个真实业务负载 | 分别验证 364000 字节 Unicode 内容的保存、分块读取、草稿清理、笔记与导出，以及真实外部归档工具的创建/解压、冲突跳过和损坏输入失败。源码与业务断言均在独立插件仓库。 |
| 生命周期 | 两个真实插件在同一固定宿主上升级本地测试版本、停用、撤销旧会话、卸载代码并重装；配置、KV 与受管用户文件保留。版本升级夹具改变包版本，业务代码相同，不能推广为任意业务 schema 迁移已验证。 |
| 重启 | 受控终止测试宿主并重启相同程序，后台自动工作恢复；三个真实业务任务的完整结果与 completedAt 精确保留，大文本与私有数据继续可读。受控中断不计作正常窗口关闭验收。 |
| 工程检查 | npm run check 通过：前端 146、供应链 25、SDK 62 项；npm run build 和九处版本对齐通过。宿主 fmt/Clippy 通过，146 项默认测试成功、8 项默认忽略；runner 的 fmt/Clippy 与 6 项测试通过。嵌入前端的 custom-protocol 构建通过。Vite 仍提示既有大 chunk。 |

宿主检查日志在 .workbench/2.2.0-p6-beta3。固定制品和受控停止证据见 fixed-host.json、controlled-stop.json。业务仓库的 docs/next3-p5-p6.md 记录独立构建日志、诊断/业务/重启报告与复跑工具。临时后台观测只读取隔离测试库，不是插件新增的数据库访问接口。

结束时测试宿主及其记录的子进程全部停止，五个隔离 SQLite 库的只读 quick_check 均为 ok，两个固定程序摘要仍与开始时一致。被替代的 beta.2 测试程序目录已清理，原失败记录与隔离数据保留。

原生窗口布局、业务界面操作与显示效果由 P7 人工验收；大规模、长时间压力、安全验证及生产迁移、正式分发仍属 P7/P8。默认忽略的外网更新/资源下载、Windows 网络设置、系统 TLS/PAC 和其他显式夹具用例不计入本轮默认门禁成功数。P5/P6 的通过不替代这些后续验收。
