本地 build.rs 只调用 version_check::supports_feature("doc_cfg")，按结果输出编译条件；对应 version_check 代码通过 rustc --verbose --version 查询编译器信息。上述事实支持来源核查，不能据此推断被检出二进制一定安全，也不能代替厂商对该 MD5 的复核。上游固定提交网页本轮未成功获取，不把本地核对写成已完成远程源码核对。
