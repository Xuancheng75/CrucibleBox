# CrucibleBox v1.9.15 插件开发说明

> 本文档记录 v1.9.15 新增的宿主能力、四个新插件的设计方案，以及新 API 的使用示例。
> 契约基准仍为 Manifest v2 / backend API v2 / renderer API v2（SDK v2 已冻结）。

## 1. v1.9.15 新增宿主能力一览

v1.9.15 扩展了宿主侧 host 方法的实现面，以下方法从 `NOT_ALLOWED` 变为可用：

| Host 方法 | 权限 | 说明 |
|---|---|---|
| `network.fetch` | `network:fetch` | HTTP 请求（ureq，30s 超时，响应 ≤50MB） |
| `notification.show` | `notification` | 后端侧系统通知（经宿主事件总线转发 WebView2 Notification） |
| `file.read` | `file:read` | 读取文件（返回 base64 编码内容） |
| `file.write` | `file:write` | 写入文件（接受字符串或 base64 数据） |
| `clipboard.read` | `clipboard` | 读取剪贴板文本 |
| `clipboard.write` | `clipboard` | 写入剪贴板文本 |
| `system.info` | 无（公开只读） | 获取系统信息（CPU/内存/磁盘/OS/网络） |

### 1.1 `api.fetch(url, opts)` — 网络请求

```ts
// backend (main.ts)
const resp = await ctx.api.fetch('https://api.example.com/data', {
  method: 'GET',
  headers: { 'Accept': 'application/json' }
})
// resp: { status: number, statusText: string, headers: Record<string,string>, body: string }
```

- 实现：Rust 侧 `ureq`（已有依赖，TLS 支持）
- 超时：30 秒硬限制
- 响应体上限：50 MB
- 权限：需在 `plugin.json` 声明 `network:fetch`

### 1.2 `api.clipboard.read()` / `api.clipboard.write(text)` — 剪贴板

```ts
// backend (main.ts)
const text = await ctx.api.clipboard.read()
await ctx.api.clipboard.write('Hello from plugin!')
```

- 实现：Rust 侧 `arboard` crate（Windows Clipboard API）
- 仅支持文本类型（图片剪贴板不在本次范围）
- 权限：需在 `plugin.json` 声明 `clipboard`

### 1.3 `api.getSystemInfo()` — 系统信息

```ts
// backend (main.ts)
const info = await ctx.api.getSystemInfo()
// info: {
//   os: { name: string, version: string, hostname: string },
//   cpu: { brand: string, cores: number, physicalCores: number, usage: number },
//   memory: { total: number, available: number, usage: number },
//   disks: Array<{ name: string, total: number, available: number }>,
//   network: Array<{ name: string, ip: string, mac: string }>
// }
```

- 实现：Rust 侧 `sysinfo` crate
- 无需额外权限（公开只读信息）
- 数值单位：内存/磁盘为字节（bytes），CPU 使用率为百分比（0-100）

### 1.4 `api.readFile(path)` / `api.writeFile(path, data)` — 文件读写

```ts
// backend (main.ts)
const data = await ctx.api.readFile('C:\\Users\\me\\file.txt')
// data: { content: string } — UTF-8 文本内容

await ctx.api.writeFile('C:\\Users\\me\\output.txt', 'Hello World')
```

- 权限：需在 `plugin.json` 声明 `file:read` / `file:write`
- 注意：`file:read/write` 表示整个文件系统能力，请谨慎授予

## 2. 新增插件设计

### 2.1 JSON/文本工具箱（`json-toolkit`）

| 项 | 值 |
|---|---|
| 类型 | renderer-only（`"backend": false`） |
| 权限 | 无 |
| 依赖 | 无外部依赖 |

**功能标签页**：

| 标签 | 功能 |
|---|---|
| JSON | 格式化 / 压缩 / 校验（错误定位） |
| Base64 | 编码 / 解码 |
| URL | 编码 / 解码 |
| 时间戳 | Unix ↔ 人类可读日期互转 |
| UUID | v4 生成（`crypto.getRandomValues`） |
| 正则 | 正则表达式测试（匹配高亮） |
| 哈希 | MD5 / SHA-1 / SHA-256（Web Crypto API） |

**架构要点**：
- 纯前端计算，无需 backend
- 使用 Ant Design Tabs 组织功能
- 所有转换实时响应（输入即转换）
- 结果支持一键复制

### 2.2 剪贴板管理器（`clipboard-manager`）

| 项 | 值 |
|---|---|
| 类型 | backend + renderer |
| 权限 | `clipboard`、`storage:read`、`storage:write`、`notification` |

**功能**：
- Backend 1 秒轮询 `api.clipboard.read()` 检测变化
- 变化时持久化到 storage（key 前缀 `clip:`，最多 200 条）
- Renderer 列表展示、搜索、置顶、删除、点击回填剪贴板
- 支持文本类型
- 清空历史功能

**消息协议**：

```
renderer → backend:
  { type: 'getHistory' }        → { items: ClipItem[] }
  { type: 'deleteItem', id }    → { ok: true }
  { type: 'clearAll' }          → { ok: true }
  { type: 'copyToClipboard', text } → { ok: true }

backend → renderer (via onMessage response):
  ClipItem: { id: string, text: string, timestamp: number, pinned: boolean }
```

### 2.3 系统信息面板（`system-info`）

| 项 | 值 |
|---|---|
| 类型 | backend + renderer |
| 权限 | 无 |

**功能**：
- Backend 调用 `api.getSystemInfo()` 获取系统数据
- Renderer 仪表盘展示：
  - CPU 使用率（Progress 组件）
  - 内存使用率（Progress 组件）
  - 磁盘使用率（每个分区一个 Progress）
  - OS 版本、主机名、CPU 型号
  - 网络接口列表（IP/MAC）
- 每 3 秒自动刷新

**消息协议**：

```
renderer → backend:
  { type: 'getSystemInfo' }  → SystemInfo object
```

### 2.4 实时汇率（`exchange-rates`）

| 项 | 值 |
|---|---|
| 类型 | backend + renderer |
| 权限 | `network:fetch`、`storage:read`、`storage:write` |

**功能**：
- Backend 使用 `api.fetch()` 调用免费汇率 API（`https://open.er-api.com/v6/latest/USD`）
- 支持货币：CNY、USD、EUR、JPY、GBP、HKD、KRW、SGD、AUD、CAD
- 货币转换器（输入金额 + 选择源/目标币种）
- 缓存汇率到 storage（30 分钟过期，key: `rates:cache`）
- 手动刷新按钮
- 汇率列表展示

**消息协议**：

```
renderer → backend:
  { type: 'getRates' }         → { rates: Record<string,number>, updatedAt: number }
  { type: 'convert', amount, from, to } → { result: number, rate: number }
  { type: 'refresh' }          → { rates: Record<string,number>, updatedAt: number }
```
