# 安全模型

插件是用户选择安装的可信代码。权限声明限制 SDK 能力，不代表 OS 沙箱。原生 backend 可以拥有当前用户的系统权限；独立进程和 Job Object 提供故障隔离、取消确认与进程树清理。

Process Service 同样执行可信本地代码。调用方需要 process:run 权限、自己的执行任务及 tools 声明；EXE 必须来自已批准、版本匹配的原生 runtime 资源清单。执行前核验包和二进制，持有禁止写入/删除的 EXE 句柄。参数以数组传递，宿主管理工作目录和环境，限制输入输出与时间，退出或取消时清理进程树。此能力允许工具访问当前用户可访问的系统，安装确认必须如实展示；不可解释为对原生依赖的安全审计。

文件引用打开时验证最终句柄路径并拒绝重解析点。目录枚举不跟随链接。文件写入和网络下载使用任务归属、受管结果目录与既有持久发布日志；失败清理暂存文件，成功后才发放 owner 绑定引用。下载要求预期字节数和摘要，沿用代理/TLS 策略。网络诊断不自动写入请求 URL、头或正文，日志上下文由插件显式提供。

Renderer 使用 opaque sandbox iframe，绑定宿主签发的 session、一次性握手令牌及 MessagePort。消息按 wire 5 契约校验，限制大小、并发、请求与会话时限。安装文件清单、包含路径、签名与完整性校验阻止越界和篡改。

仍挂载的 renderer 页面由可信主窗口定期续签有限租期，休眠恢复或新请求也会先检查续期；插件 iframe 无权自行续签。续期核对安装记录、版本、目录、入口、权限及启用状态，不重载正常页面，不更换其身份或清空重放记录。过期租期仍拒绝 RPC/资源访问；已经撤销的会话不能恢复。未使用的签发票据到期清理，已挂载记录保留到显式释放，最多 32 个。停用、卸载和页面销毁同时释放关联准入记录。

宿主注入的 frame runtime 将客户端相关 ID 映射为有序的 `renderer-N` 上行帧，并将回应映射回客户端 ID。renderer 准入保留最高序号、最近 64 个编号的重放窗口及有界并发记录。允许窗口内首次到达的请求，拒绝重复或过旧请求。同一会话的取消可以先于较早编号的请求到达。采用不透明 ID 的其他会话继续遵守原 4096 次预算。续期具有有限等待期限，不自动重发业务操作；原生授权明确失效，或携带直接浏览器下载权限的页面无法续期时，销毁页面并撤销能力。其他连接故障可保留没有该浏览器能力的本地界面供用户重试；原生访问仍受有效租期约束。

平台按发起者推导身份，不接受插件伪造 owner；服务提供者由已安装 manifest 的依赖解析决定。存储、文件引用、任务结果与执行报告均校验归属。长任务取消只有在执行器结束或进程树停止后才进入终态。

后端在首个能力请求选择 `backend-seq-N` 后使用严格递增的序号；原生 SDK 的编号分配和输出共用锁，JS runner 映射 wire 与客户端编号。采用旧不透明编号的后端继续使用 4096 次历史预算，不能在已接受请求后切换方式重置记录。两种方式均先验证会话、进程绑定、安装身份和权限，再更新请求记录；失败和并发上限拒绝不推进高水位。

安装经 staging/journal/目录原子替换及数据库配对恢复，失败保留旧安装和数据。卸载保留配置、KV、迁移标记和用户文件。依赖方仍在使用的服务不得静默破坏。

分发支持 Ed25519 插件签名、独立资源包校验、SBOM、制品证明和强制签名更新。当前没有 Windows Authenticode 证书；签名 updater 的真实安装切换须单独验收。

主题 v2 的 CSS 经解析、根节点限定和关键帧改名，不接受外部 URL、导入规则及脚本。主题素材由文件引用导入用户数据区，限静态图片或字体，通过随机令牌与内容 ID 的专用地址读取，不暴露任意文件路径；字体要求开放许可和随附正文。`theme:assets` 是独立声明权限，素材在插件卸载后保留。应用主题时，渲染页面能看到已使用素材的地址，因此这不是素材保密边界。自定义 CSS 可改变或遮挡网页控件，设置页和独立原生快捷键提供恢复默认主题的入口；Windows “外观”菜单已从 beta.4 源码移除，启动显示仍待验收。主题限制不替代浏览器或系统的安全更新。
