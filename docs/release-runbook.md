用户于 2026-11-05 明确授权公开发布 2.1.1 并更新本机 Portable。先通过 PR 的 Windows/Rust 门禁，再合并并创建不可变版本标签。工作流构建带 updater 签名的安装器、Portable、SBOM 与证明并上传到草稿 Release；发布执行者补齐独立插件附件、清单和说明后发布草稿，再同步稳定渠道的 latest.json 与 plugins.json。签名 updater 的真实安装切换仍须单独验收，不运行本机额外安装实例。插件独立分发，其目录、版本清单与业务验收不进入底座源码树。

本次按用户发布指令进入正式发布，不将此前未收到的 P7 原生界面、长时会话、正常窗口关闭重开及真实办公软件结果写为通过；发布说明保留这些未测边界。当前七个插件的构建、固定宿主接口、安全扫描和文件完整性验证单独记录，已撤下的文档工作台和 OCR/Office 资源不加入当前分发。更新本机时保留原用户数据、插件配置与输出，原主题草稿不自动覆盖。
