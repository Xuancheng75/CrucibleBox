# 2.1.1 插件页面长期会话修复

日期：2026-10-31；后端补修：2026-11-01。归入 P1 生命周期补修、P2 平台候选更新。代码与自动回归已完成；真实窗口长时运行、休眠恢复、草稿保留及业务集成仍在 P7 统一验收。

## 问题与修复

原页面会话从创建起固定 30 分钟失效，前端到期清空页面；没有续期入口。另外，渲染器每次轮询都会消耗一次 4096 请求的历史记录预算，长时间任务轮询也会耗尽会话。

当前由宿主已挂载页面在半租期时续期，返回前台和请求前也检查租期。续期沿用原 token、握手身份和重放记录，不重新加载页面。原生入口重新核对主窗口来源、owner、已启用的安装记录、版本、目录、入口及权限；停用、卸载、页面销毁会撤销相应会话。休眠后允许所属主窗口重新授权已激活的过期会话；普通资源和 RPC 入口仍拒绝过期会话。

宿主 frame 为渲染器请求分配递增 wire ID，并将结果映射回插件原来的关联 ID。原生只保存序列高水位及在途请求，不再为渲染器累积完整历史；续期保留高水位，旧请求不能重新执行。原有非渲染器 opaque ID 会话继续使用原预算。Manifest/API 6、wire 4 不变。

续期有单次请求期限，同期调用共用一次续期；业务操作不自动重试。临时通信失败显示恢复入口并保留本地草稿，RPC 仍须授权。身份失效或具有浏览器直接下载权限的页面会关闭，防止撤销后继续使用浏览器能力。会话数量沿用 32 的限制，销毁释放占用。

## P7 补充人工检查

1. 在同一个插件页面编辑未保存草稿，保持打开超过 30 分钟及 60 分钟，持续操作和完全不操作分别检查；页面不重载，后续保存、文件选择及任务查询正常。
2. 切换到其他工具箱页面后返回，后台任务和草稿仍在；任务轮询超过原 4096 次阈值后仍可查询。
3. 锁屏、休眠超过租期后恢复，核对连接、草稿和后台任务实际终态；出现通信失败时，手动恢复不会重复执行业务写入。
4. 停用、升级、卸载和关闭插件页后，旧页面不能继续调用；重新打开建立新会话。

本补修不运行受卡巴斯基拦截的旧文档后端，不解除其安全阻塞，也不替代完整业务、Office 或正式 Portable 验收。
