## 当前可用链路

- 插件通过 `exports` 注册能力，通过 `dependencies` 声明消费。`providerId` 固定提供者。省略时只选择 `interchangeable: true` 的导出，按兼容接口版本降序和插件 ID 升序选择。`optional: true` 允许缺失或无兼容版本时启用。调用可区分未声明、缺失、版本不兼容、循环依赖和未导出方法。
- SDK 的 `resolveCapability(id)` 和 `service(id, method, params)` 使用同一解析。查询返回 `providerId` 和 `export`，只表示当前可解析的清单绑定。调用时检查被选执行包的文件摘要，不在执行失败后重放请求。对状态、输入隐私或提供者身份有要求时固定 `providerId`。已启用消费者依赖的提供者按现有停用保护处理，升级会验证变更前后受影响的依赖链。
- [协议 gateway](../src-tauri/crates/next2-protocol/src/gateway.rs) 负责发现、选择、依赖遍历和会话准入。宿主从启用记录读取经过审批的清单，某个包的清单损坏只影响相关路由。载荷、权限、签名和确认仍在安装与实际使用处校验。Worker 回调的内建调用只查自己的审批清单。
- [内建 Provider](../src-tauri/src/next2_host/platform_service.rs) 按命名空间在可信装配中注册。方法、权限和调用上下文由公共契约定义，宿主会话执行裁决。`theme.get/list/preview/set/commit/rollback`、`dialog.open/confirm`、`notification.show` 通过受信主界面完成，开发分支契约限制为 renderer。`theme.assets.*` 和文件对话框 `files.choose` 保持既有执行路径。
- `logging.write` 要求 `logging:write`。SDK `writeLog` 写入已有插件日志，宿主记录插件身份、时间、来源、请求 ID 和适用的任务 ID。插件提交明确的日志文本，宿主不会把业务请求参数或令牌自动写入日志。
- `background: true` 使已启用服务在安装恢复后启动。依赖先于服务启动，失败写入该服务的插件日志，其余服务继续。后台插件可省略 `renderer`，此时要求有后端，且不能声明导航和投递文件界面。工作台的服务配置、启停和卸载仍可用。发布形态的构建 CLI 支持 `init <新目录> provider`，模板目标版本为 2.2.0。
- 旧数据迁移把数据和标记一起发布。旧源和无迁移标记的目标同时存在时，保留两边并明确报告冲突。人工核查前不要移除目录或手写迁移标记。相关源码在 [data_dir.rs](../src-tauri/src/data_dir.rs)，测试使用 `.workbench/temp` 的夹具。

## 能力调用示例

Provider 的 `exports` 可以声明 `{ "id": "sample-sum", "version": "1.0.0", "methods": ["sum"], "interchangeable": true }`。消费方将 `{ "id": "sample-sum", "version": { "min": "1.0.0", "maxExclusive": "2.0.0" } }` 加入 `dependencies`。JavaScript 和 TypeScript 通过公开 SDK 调用。

```js
const binding = await api.resolveCapability('sample-sum')
const result = await api.service(binding.export.id, 'sum', { numbers: [7, 19] })
```

新增插件 Provider 时修改该插件清单和后端实现。新增内建命名空间时，在契约中定义方法、参数、结果、权限和上下文，在可信装配中注册处理器，运行 `npm run generate:next2` 并补协议和真实调用测试。

```powershell
$env:CARGO_TARGET_DIR = Join-Path $PWD '.workbench/2.2.0-target'
cargo +stable-x86_64-pc-windows-msvc build --locked --offline --manifest-path src-tauri/cruciblebox-plugin-host/Cargo.toml
cargo +stable-x86_64-pc-windows-msvc build --locked --offline --manifest-path packages/cruciblebox-next2-native/Cargo.toml --example arithmetic
$env:CRUCIBLEBOX_NEXT2_TEST_BACKEND = Join-Path $env:CARGO_TARGET_DIR 'debug/examples/arithmetic.exe'
cargo +stable-x86_64-pc-windows-msvc test --locked --offline --manifest-path src-tauri/Cargo.toml
cargo +stable-x86_64-pc-windows-msvc test --locked --offline --manifest-path src-tauri/Cargo.toml next2_native_installed_backend_runs_cancels_crashes_and_upgrades -- --ignored
```
