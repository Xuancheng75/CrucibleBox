# CrucibleBox 2.1.0-beta.1 开发计划

> 状态：执行中  
> 基线：2.0.1 / commit `b38133d4eedfd793a1c2b2500f7e097391371526`  
> 发布目标：`tauri-v2.1.0-beta.1`，仅更新 `tauri-beta`  
> 实时进度与接力记录：[2.1.0-beta.1-progress.md](2.1.0-beta.1-progress.md)

## 1. 版本目标与约束

本版本完成 Tauri 单宿主化、插件平台 v3、统一网络与任务基础设施、性能优化和第一方插件专业化。用户最终只看到五个中文插件：

| 用户名称 | 内部 ID | 合并来源 |
| --- | --- | --- |
| 文档与知识库 | `document-engine` | Document Engine、快速解压 |
| 开发环境管理 | `unienv` | UniEnv |
| 图片与音视频 | `media-tools` | GIF 编辑器 |
| 数据与接口工具 | `developer-tools` | JSON/文本工具箱 |
| 笔记与剪贴板 | `productivity-tools` | 日记、剪贴板、骰子、转盘、汇率 |

主题管理并入“设置 → 外观”，系统信息并入“设置 → 系统诊断”。英文内部 ID 只用于兼容路径、数据库和协议，不作为用户品牌展示。

强制约束：

- 不推送或提交到 GitHub；所有工作保留在本地工作树，除非用户后续明确授权。
- 不覆盖、回滚或删除开始执行前已有的未提交修改。
- 不新增 SHA-256、哈希校验或类似防御性校验；已有发布签名和制品校验不在未获授权时扩大或删除。
- Electron 冻结线必须在 Tauri 对等能力和测试确认后删除，不能先删后补。
- Plugin SDK v2 保持兼容，新能力使用 Manifest/API v3。
- 文件输出默认不覆盖原件；长任务进入统一任务中心并可取消、重试。
- 外部 AI 默认关闭，凭据不得进入普通设置和日志。

## 4. B00：基线与版本

- 保存工作区快照、Git diff、基线提交和状态清单。
- 修复 Tauri 前端现存构建问题，重点检查 `App.tsx` 的重复声明和测试版角标表达式。
- 将宿主、前端、Cargo lock 和根工作区版本统一为 `2.1.0-beta.1`；更新版本对齐脚本。
- 插件版本：文档与知识库 `0.11.0-beta.1`，开发环境管理 `0.12.0-beta.1`，三个新合并插件均为 `0.1.0-beta.1`。
- 记录进程启动、数据库打开、恢复、窗口创建、首屏、插件列表和插件握手时间。
- 性能预算：冷启动中位数 ≤1.5 秒，热启动 ≤800 毫秒，页面反馈 ≤100 毫秒，插件列表暖读 ≤200 毫秒，普通插件 ≤500 毫秒显示界面或骨架，空闲 CPU <1%，不含模型 worker 的空闲内存目标 <250 MiB。

## 5. B01：宿主 RPC 与权限

- 实现 `dialog.open`、`shortcut.register/unregister` 和真实的 `event.emit/subscribe/unsubscribe`。
- 将 `system.info` 纳入共享类型、RPC 白名单、权限、sidecar 信封和 SDK。
- 文件写入统一为 UTF-8 文本或 Base64 二进制两种显式请求。
- 建立结构化错误：`PERMISSION_DENIED`、`UNSUPPORTED_CAPABILITY`、`RESOURCE_OUT_OF_SCOPE`、`LIMIT_EXCEEDED`、`CANCELLED`、`TIMEOUT`、`HOST_VERSION_TOO_OLD`、`INVALID_ARGUMENT`、`IO_ERROR`、`NETWORK_ERROR`。
- 建立契约一致性测试，禁止“SDK 有声明但宿主无实现”和“宿主有实现但协议不可调用”。

## 6. B02：Electron 移除

- 将 UniEnv renderer 所需纯类型和展示逻辑迁入插件自身；当前 Rust 语义测试迁到 Rust，纯冻结实现测试删除。
- 根 npm 脚本改为 Tauri、插件和供应链入口。
- 删除 Electron、electron-builder、electron-vite、electron-updater、fuses、rebuild 等直接依赖并重建锁文件。
- 删除 Electron 构建配置、fuse/冒烟脚本、旧发布工作流和 CI Electron job。
- 确认无活引用后删除 `electron/`、`database/`、`plugin-system/`。
- 保留冻结 tag 和 `docs/history/`；遗留注册表改为历史索引。

## 7. B03：统一网络与代理

- Rust 宿主提供唯一网络策略、客户端和诊断服务。
- `direct` 禁用所有代理；`system` 仅用 Windows 系统代理/PAC；`manual` 仅用指定 HTTP/HTTPS/SOCKS5；`auto` 为有效手动代理优先，否则系统代理。
- 覆盖应用更新、市场、SDK 网络、开发环境版本与下载、文档模型、外部 AI。
- 设置页提供代理格式校验和 DNS/TCP/TLS/市场/更新清单分阶段测试。
- 代理凭据进入 Windows 凭据库，任务只显示脱敏路由。
- 网络任务返回配置模式、实际路由、脱敏代理和回退原因。

## 8. B04：统一任务与市场

- 状态统一为 `queued/running/paused/waiting-user/completed/failed/cancelled`。
- 一个市场任务贯穿目录、下载、校验、预检、确认、安装、激活和完成。
- 删除右下角常驻任务浮层；顶栏/侧栏只显示紧凑任务入口，市场卡片显示自身进度。
- 等待确认只显示安装弹窗；取消后清理临时文件并终结任务。
- 宿主推送任务变化，前端仅在重连时获取快照，移除高频轮询。

## 9. B05：性能优化

- 首屏前只执行目录检查、必要迁移、数据库打开和关键事务恢复；市场、更新、模型、诊断和缓存清理延后。
- OCR、媒体和外部工具进程首次使用时启动。
- 数据库改为单写入队列和有限只读连接；网络/文件操作不得持锁。
- 插件列表请求去重、缓存并通过安装/卸载事件失效。
- 页面离开后默认卸载，后台状态进 zustand；iframe 保活有数量上限和 LRU 回收。
- 长列表虚拟化，大文档、日志、剪贴板和 JSON 分段加载。
- 系统静态信息缓存，动态指标限频；阻塞 I/O 进入专用任务池；大文件流式处理。
- 进度事件最多每 100 毫秒一次，相同进度不重复发送。

## 10. B06：Plugin SDK v3

- Manifest v3 新增 `minimumHostVersion`、`trustLevel` 和结构化 `capabilities`。
- 通用能力包括 storage、fs、network、process、archive、tasks、events、ui、system、crypto、credentials、pluginData。
- `standard` 使用带范围能力；`full` 申请 `host:full-trust`，安装和升级时单独确认并持续显示高风险标记。
- 市场高信任插件必须签名；未签名包只能开发者模式安装。
- 长操作只返回 `taskId`，不占用单次 RPC 等待。

## 11. B07：文档与知识库

功能区固定为文件工作台、PDF 工具、格式转换、文字识别、内容提取、知识库预处理、自动化流程、任务与质量、模型与缓存。

- 输入支持 PDF、Office、文本、Markdown、HTML、XML、JSON、CSV、图片、EPUB、邮件和常用归档。
- 快速解压先补齐归档浏览、选择解压、创建、密码、分卷、冲突、取消、重试和错误诊断，再合并；不得把未完成能力直接隐藏到新页面。
- PDF 支持合并、拆分、重排、删除、旋转、裁剪、压缩、水印、页码、书签、可搜索化、密码、附件、元数据和差异比较。
- Office/文本支持可靠解析和互转，结果必须可重新打开并通过结构检查。
- OCR 提供快速/高精度，中英混排、旋转、倾斜、透视、去噪、切片、标准 DB 后处理、动态宽度、低置信度重试、版面、表格、公式、图表、题注和码识别。
- 使用桌面的三份 PDF 建立回归：扫描笔记、线性代数教材及 `78_361002200708112019_24.pdf`；记录页数、文字来源、OCR 置信、结构、表格/公式和分块结果。
- RAG 支持语料项目、增量构建、清洗、跨页修复、去重、脱敏、结构/语义/混合/父子分块、真实 tokenizer、本地或外部增强、本地或外部向量、JSON/JSONL/CSV/Parquet及常用知识库适配。
- 工作流节点覆盖导入、解压、预处理、OCR、解析、提取、清洗、脱敏、去重、分块、增强、向量和导出，并支持条件、试运行、预设、检查点和恢复。

OCR 验收：高精度总体中文字符错误率相对当前基线至少降低 20%，英文词错误率不退化，检测 F1 不低于基线，CPU 单页耗时不超过基线 2 倍。

## 12. B08：开发环境管理

- 修正 direct、华为、阿里、TUNA、npmmirror 配置和真实路由。
- 镜像优先并允许关闭官方回退；镜像与代理分别展示。
- 全部工具使用结构化版本条目，区分上游最新、安全可安装、已安装和当前版本；无可信元数据的新版本只展示。
- `current` 指向版本根，shim 只追加一次内部目录；临时链接、版本探针、原子切换和失败回滚。
- 增加项目版本清单、一键安装、差异检查、锁定文件、临时终端、下载缓存、离线安装和环境健康报告。

## 13. B09：图片与音视频

- 图片查看、转换、裁剪、旋转、缩放、批处理、压缩、重命名、EXIF、水印、拼接、长图、九宫格和雪碧图。
- 可选本地背景移除、超分辨率和去噪。
- 动画时间轴、帧编辑、速度、循环、反向、调色板、抖动、帧差优化及 GIF/APNG/WebP/序列互转。
- 音视频裁剪、拼接、转码、抽帧、提取音频、视频转 GIF、字幕和音量处理。
- 使用非破坏项目、受控撤销、代理预览和后台导出；不实现复杂多轨剪辑。

## 14. B10：数据与接口工具

- JSON/JSON5/YAML/TOML/XML/CSV/TSV 格式化、验证、互转、大文件查看、查询、Schema、差异、合并、补丁和数据变换。
- 文本差异、正则、编码、Base64、URL、HTML 实体、Unicode、十六进制、UUID、ULID、时间戳、Cron、SHA/HMAC/JWT 工具；此处只保留用户主动使用的数据工具，不为宿主业务新增哈希校验逻辑。
- HTTP/REST/GraphQL/WebSocket，请求集合、环境、上传、响应查看、变量提取和受限脚本；凭据进入系统凭据库并遵守统一代理。
- 不实现专业负载测试。

## 15. B11：笔记与剪贴板

- 日记、普通笔记、每日笔记和快速收集共享模型；Markdown、公式、附件、模板、标签、全文搜索、反向链接、日历、版本历史、回收站、备份和可选本地加密。
- 剪贴板支持文本、图片、文件、搜索、置顶、标签、重复合并、保留策略、隐私暂停、排除名单和快捷处理。
- 内容可发送到笔记、数据工具或文档工具。
- 合并骰子、转盘、权重抽签、随机分组、汇率、单位、时区、百分比、税率和复利；明确非赌博、法律抽签或投资建议工具。

## 16. B12：迁移

- 迁移映射：archive→document，gif→media，json→developer，diary/clipboard/dice/turntable/exchange→productivity，theme/system→宿主。
- 每次迁移预检源版本和记录数，写入新 namespace，校验记录/附件，写完成标记；成功前保留旧数据，重复执行不得产生重复内容，失败回滚新写入。
- 旧插件保留一个稳定周期的只读导出和跳转入口，不再新增功能。

## 17. B13：发布验收

- Rust fmt、clippy、workspace tests 全绿。
- Tauri 前端生产构建全绿。
- 五个正式插件独立 clean/typecheck/test/build 全绿。
- 从 2.0.1 升级保留数据库、配置、插件和用户数据。
- Electron 代码、依赖、CI和发布配置不存在。
- 四种代理真实生效；市场无常驻遮挡；任务不重复。
- 五个插件核心流程、迁移、取消、失败、重试和重启恢复通过。
- 达到性能预算。
- Windows x64安装、启动、升级和卸载通过。
- 生成安装包、更新清单、插件目录、五个插件包、SBOM、校验和及 attestation；本次开发阶段不推送 GitHub，发布动作等待用户后续授权。

## 18. 分支与提交边界

每个工作包使用独立 `codex/2.1-beta1-*` 分支和 Conventional Commit。当前阶段只修改工作树，不创建提交、不推送。不得在同一工作包中同时删除 Electron、修改 v3 契约并合并全部插件。

## 19. 非目标

- 账户系统和第三方上传市场。
- 内核驱动或管理员常驻服务。
- 多人在线协作。
- 内置长期运行向量数据库。
- 创建法律意义的 PDF 数字签名。
- 专业多轨视频剪辑和压力测试。
- 使用用户文档训练 OCR 模型。
