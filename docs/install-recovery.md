# 安装与数据恢复

当前只安装 Manifest/API 6 包，且必须满足宿主版本范围、文件清单、资源与服务依赖约束。原生代码、发布者变化与权限扩张要求明确确认。

安装先生成不可变预览令牌，再经 staging、journal、旧进程停止、目录交换和数据库更新提交。中断恢复保留程序与元数据配对；无法确定的一项明确阻塞，不伪造成功。

启动时禁用 API 5 及更旧执行记录，保留插件包、原始配置/KV、迁移标记及用户文件。升级和卸载重装按稳定身份保留数据。宿主不再识别具体业务表、业务键或插件名称，也不自动转换旧业务格式。

2.1.1 卸载在停止实例后删除 API 6 受管代码目录内的全部版本、插件独占资源目录和该清单身份的市场下载缓存。配置、KV、用户数据目录及安装根目录中未登记为程序的文件保留；结果列出仍有文件的保留目录。历史包无法可靠归类的文件不自动删除。资源缓存和代码清理失败会保留卸载日志并报告失败；数据库记录已提交删除后仍可重试或启动恢复，完成剩余清理。

安装记录 ID 用于实例操作，清单身份用于版本匹配和重装数据关联。启用先通过准入并启动，成功后保存启用选择；退出应用只停止实例，不改写该选择。

开发现场只用本地 Git 保存源码，不另建路径备份、补丁或 bundle。现有用户数据不因源码整理而删除。程序或数据库不兼容降级不属于当前保证。
